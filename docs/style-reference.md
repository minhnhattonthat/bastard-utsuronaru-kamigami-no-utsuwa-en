# Style reference

Matches the pilot (first scene, `s0010`, batch b011). Read this and `glossary.md` before translating.

## Voices
Each row names the JP markers and the English that carries them. A line any speaker could have said is a mistake.

| Speaker | JP markers | English devices |
|---|---|---|
| Narration | `であった`, literary kanji, long periods | Literary past tense, unhurried, slightly archaic; no slang; keep the images. Split a very long sentence only where the JP pauses. "It was then." for `その時だった`. |
| D.S. | `俺様`, `テメエ`, `〜ねえ`, `〜だぜ`, `ワケ`, `バカ` | Arrogant, vulgar, funny. "the great me" for `俺様`; "punk", "you bastard", "the hell", "damn", "ain't", dropped subjects. Turns syrupy for Yoko (`ヨーコさん` always -san, `キミ` = you, gentle tone), then snaps back. |
| Vai | `〜ってんだ`, `俺`, `アンタ`, `〜かな`, `〜だよ` | Young, hot-headed, a straight man for D.S.'s abuse. "gonna", "y'know", "hang on", "the hell". Less crude than D.S. |
| Joshua | `私`, `〜のだ`, `〜ではない`, polite to D.S. | Formal, no contractions, measured; "I shall", "forgive me". |
| Blad | `ワシ`, `〜のだ`, `ぬうう`, `なっとらん` | Pompous old knight, no contractions: "I shall", "you there"; `なっとらん` = "Disgraceful!" (his catchphrase). |
| Bol | `それがし`, `〜でござる` | Mock-archaic samurai. "this one" for `それがし`, "forsooth" for `ござる` at line ends, "good sir". Comic. |
| Macalpine | `私`, `貴様`, `ククク`, `〜よ` | Cold, smug, no contractions; "Heh heh heh". |
| Jorg | `俺`, `〜ぬ`, `知らぬ` | Terse, bitter, few words. |
| Yngwei | `私`, `〜だな`, `かたじけない` | Calm, courteous, no contractions: "I am obliged to you". |
| High Ninja | `俺`, `貴様`, `ククク`, `フハハ` | Contemptuous, in command, no contractions; "Heh heh heh", "Hah hah!". |
| Sheila | `私`, `〜下さい` | Well-bred, plain, formal, no contractions. |
| Sykes | `私`, `君たち`, `〜だ`, `諸君` | Glib scholar: "gentlemen", "in brief", amused at himself; few contractions. |
| Zakk | `俺`, `お前`, `〜だぜ`, `〜様` | Cocky teen, righteous and dense: "gonna", "you guys", "the great Zakk-sama". |
| Ros | `アタシ`, `〜わよ`, `アンタ`, `バッハハーイ` | Camp and breezy: "Oh my", "toodle-oo", "Buh-bye-bye!". Says he's no queen (オカマ), just refined. |
| Shella | `私`, `〜だ`, `〜ない` | Grave, poetic, a little stiff; a bard in men's clothes. |
| Ba Thory | `俺様`, `貴公`, `うふっ` | Blustering, spitting, stammers when flustered ("Cuh-cuh-cocky"); turns coy when flattered ("Ufu"). |
| Old or formal speakers | `わし`, `じゃ`, `のう`, `〜であろう`, `貴様`, `〜ぬ` | Stiff, archaic: "I shall", "you dare", "boy", "eh?". |
| Women | `〜わ`, `〜のよ`, `かしら` | "I wonder", "you know", "dear" as fits the character; Nei is commanding, Yoko warm. |

Update this table when a new voice is settled (name, markers, devices).

## Example pairs
| JP | EN | Why |
|---|---|---|
| ……やい。テメエがそうしてるのは勝手だがな、俺様には助けを待ってる大事な大事な女がいる……んだ。多分。 | ...Hey. Mope all you want, punk, but the great me has a precious, precious woman waiting to be rescued... I think. | `俺様` and `テメエ` carried; the `多分` beat kept as its own fragment |
| ……ひとつ思い出した。ヴァイって野郎は確かバカだ / 何で！ | ...I just remembered something. That guy Vai is an idiot. / What for! | Comic timing: short, deadpan |
| おーい。俺も癒されてるぞ | Uh, hello? I'm getting healed too. | The joke over the literal `おーい` |
| 深海の底を思わせる、重苦しく、静寂に支配された眠りであった。 | It was a heavy sleep, ruled by silence, like the floor of a deep sea. | Narration stays literary |
| ヨーコ……さん | Yoko... -san. | Honorifics kept even when split by a pause |
| 聖玉 / ヨーコ玉 | Holy Orb / Yoko orb | |

**Corrected example:** `何で！` was first read as "Why!"; "What for!" keeps the indignant, childish snap. Prefer the line that sounds like an argument.

## Rules from earlier batches
- 珠 / 玉 for the orb: "orb".
- Speaker labels are hints: a line tagged with a name can be narration (third-person description).
- Keep the 『彼』 quote marks in the opening: 'him', 'he'.
- Keep lines plain ASCII; `--` for ――; `...` for ……; `!?` for ！？.
