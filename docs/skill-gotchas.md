# Skill gotchas

One line per gotcha: the reference file it belongs in, then the fact.

- references/translation.md: with no subagents allowed (Orca worker), per-batch tokens decide the run. A batch line of `N speaker|JP` with the speaker only on change, identical lines deduped, `{n}` stripped, and output `N English` with a wrap tool to the box's pixel budget, is smaller than the template's `id<TAB>speaker<TAB>form<TAB>limit<TAB>jp` (saving not measured). Structured stat sheets and item descriptions can be generated from field tables instead of translated line by line.
- references/translation.md: `assets/batches.py` has no notion of authored vs wrapped English; when the tool wraps, keep `en` as the wrapped form and rebuild the authored form by `{n}` -> space (`batches.authored`) so repeats in other box widths re-wrap correctly.
- references/translation.md: a full review pass by one solo worker costs about 1.8 MB of JP/EN pairs (about 1.7M tokens: a 113 KB file measured about 100k), so at most 1 of 17 files per worker when no subagent or codex is available; `codex exec` quota can run out and every parallel run then exits rc=1 with no report: check the first log before waiting on the rest.
- references/emulator-qa.md: a marker tour cannot catch a run-time widening overflow: short marker ids fit the save list, while real English map names (16+ ASCII chars) doubled in a fixed full-width buffer and hung it. Re-run the menu and save scenes on the real text build, and on a blank memory card (emu.py --sav) for the format prompt.
- references/emulator-qa.md: the PCSX-Redux dynarec (emu.py default) hides R3000 load-delay bugs, and so does unicorn: a hook with `lbu $t1; sb $t1` drew fine and was blank on the interpreter. Run hook scenes once with `--debugger`, and assert over the assembled hook that no load is read by the next instruction (`tests/test_engine.py`).
- references/translation.md: `is_mark`-style code that exempts "only punctuation" lines hides real text: 33 `……` and `？` lines shipped full-width. Keep a `script/keep_jp.txt` from the start. Text scanners that stop at half-width kana bytes also dropped a whole string ending in `｡`.
- references/platform-ps1.md: jPSXdec isn't needed for STR v2 captions. A small Python encoder (`tools/mdec.py` here: MPEG-1 B.14 table, column-order macroblocks, end marker `0111111111`) re-encodes originals byte-identical, which proves the table, and re-encoding only macroblocks under a caption keeps the rest of each frame untouched. ffmpeg logs `ac-tex damaged` even on good frames, so compare samples, not its log. `multiprocessing.Pool` hung on Windows under the agent shell; plain loop and a cache were enough.
- references/emulator-qa.md: a marker tour can't show a label clipped by a fixed sub-menu box or a help line scrolled off by its own wrap, because those menus only open on a key press and marker ids are short. Walk every battle command and sub-menu on the text build with `play.py` from a battle savestate (here: 5 clipped labels, 4 help lines).
- references/emulator-qa.md: when scripts are native code, text coverage doesn't need story state: replace one event's code in RAM with generated print calls, one per string (`tools/debug/sweep.lua`). 6,332 of 6,332 script lines drew in about 25 minutes at 8 jobs, against 1,640 from 844 warped scenes. It proves the line draws in its box, not that play reaches it.
- references/emulator-qa.md: free RAM measured on one scene isn't free on all: generated code at 0x801F0000 was overwritten on one map, and the emulator stopped advancing frames with no error (exit 124). Check the area is zero before writing, and write a done flag whose low 16 bits don't sign-extend (`sw` to 0x801EFFFC went to 0x801DFFFC, so the done test never fired).
