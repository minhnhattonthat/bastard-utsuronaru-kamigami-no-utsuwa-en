# Glossary - Bastard!! Utsuronaru Kamigami no Utsuwa

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (options and reasons in docs/decisions.md)
- Honorifics: kept. Name order: Western (given name first).
- Romanisation source: official English names where they exist (the Viz manga is the first place to check), else an earlier fan patch (DeJap's Super Famicom patch), else Hepburn without macrons.
- Credits: English.
- Register / flavour: filled in at phase 6.
- Abbreviations: full names and terms everywhere, prefer engine changes over shortening. `D.S.` is canon, not an abbreviation of convenience.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ / …… -> ..., ！？ -> !?
- Voice notes: phase 6.
